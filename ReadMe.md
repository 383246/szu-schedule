# 简介

## 什么是 SZU Schedule?

SZU Schedule 是深圳大学智能课表网页版，一个纯前端的课表管理工具。无需安装任何软件，直接用浏览器打开即可使用，支持手机端和电脑端。

## 特性

- 📅 **多种导入方式**：支持 .ics 文件导入、JSON 数据导入、图片 OCR 识别导入
- ⏰ **课前提醒**：根据不同教学楼设置通勤时间，自动提醒出发
- 📝 **课后笔记**：每节课可记录文字笔记，支持附件上传
- 📱 **移动端适配**：响应式设计，手机电脑都能用，支持 PWA 添加到主屏幕
- 🌙 **深色模式**：支持浅色/深色主题切换
- 📊 **课表统计**：本周课程统计、心情记录
- 🏖️ **节假日提醒**：自动显示假期倒计时
- 💾 **本地存储**：所有数据保存在浏览器本地，隐私安全

## 文件说明

| 文件名 | 说明 |

# 使用方法

## 快速开始

1. 双击打开 `szu_schedule.html`
2. 点击右上角「导入」按钮
3. 选择一种导入方式导入课表
4. 开始使用！

## 导入方式详解

### 方式一：油猴脚本一键导出 .ics（推荐 ✅）

深大教务系统不支持直接导出 .ics，但我们可以用油猴脚本一键导出，只需 3 步：

**第 1 步：安装油猴插件**
- Chrome/Edge 浏览器：安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
- 安装后浏览器右上角会出现一个黑色的猴子图标 🐵

**第 2 步：安装导出脚本**
- 用浏览器打开 `szu_schedule_export.user.js` 文件
- 油猴会自动弹出安装页面，点击「安装」即可
- 或者：点击油猴图标 → 添加新脚本 → 把 `szu_schedule_export.user.js` 的内容全部复制粘贴进去 → Ctrl+S 保存

**第 3 步：一键导出**
- 登录[深大教务系统课表页面](https://ehall.szu.edu.cn/jwapp/sys/wdkb/*default/index.do#/xskcb)
- 等页面加载完，右上角会出现一个紫色的「📥 导出课表」按钮
- 点击按钮，稍等 1-2 秒，自动下载 `.ics` 文件
- 打开 `szu_schedule.html` → 点「导入」→ 选 `.ics` → 上传刚下载的文件

> 💡 导出的 .ics 文件也可以直接导入手机日历、Outlook 等，跨平台同步课表！

### 方式二：JSON 数据导入

1. 安装油猴脚本 `szu_schedule_export.user.js`
2. 登录深大教务系统课表页面
3. 脚本会自动添加导出按钮，点击导出 JSON
4. 复制 JSON 数据，粘贴到导入页面的 JSON 标签中

### 方式三：图片识别导入

1. 截取课表图片
2. 打开导入页面的「图片」标签
3. 上传图片，系统会自动识别课程

## 移动端使用

### iPhone
1. 用 Safari 打开 `szu_schedule.html`
2. 点击分享按钮 →「添加到主屏幕」
3. 从主屏幕点击图标即可像 App 一样使用

### Android
1. 用 Chrome 打开 `szu_schedule.html`
2. 点击菜单 →「添加到主屏幕」
3. 从主屏幕点击图标即可使用

# 功能说明

## 课前提醒

在「我的」页面可以设置各教学楼的通勤时间和提前提醒时间。系统会自动计算下节课的出发时间并进行倒计时提醒。

## 课后笔记

点击课表中的任意课程，可以：
- 记录文字笔记
- 上传附件（单文件 < 5MB）
- 查看历史笔记
- 记录今日心情

## 深色模式

点击右上角 🌙 按钮切换浅色/深色主题。

# 本地运行服务器

如需在手机上访问，可以启动本地 HTTP 服务器：

```bash
# 进入项目目录
cd 111

# 启动 Python HTTP 服务器
python -m http.server 8080

# 然后在手机浏览器访问 http://你的电脑IP:8080/szu_schedule.html
```

注意：手机和电脑需要连接同一个 WiFi。

# 技术栈

- 纯前端实现：HTML5 + CSS3 + Vanilla JavaScript
- 数据存储：localStorage
- OCR 识别：Tesseract.js
- 响应式设计：CSS Media Queries
- PWA 支持：可添加到主屏幕

# 注意事项

- 所有数据保存在浏览器本地，清除浏览器数据会导致丢失
- 建议定期使用「导出备份」功能保存数据
- 图片识别为实验性功能，识别准确率可能有限
- 本工具仅供学习使用，请勿用于商业用途
